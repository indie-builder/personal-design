# Triage Labels

使用 mattpocock/skills 默认的五类角色。下表是配置约定，不表示标签已经在 GitHub 创建；后续实际 triage 时先检查现有标签，再在获授权的范围内应用。

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可由 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 不计划处理 |

其他已有标签继续保留，不因本配置重命名或删除。技能提到角色时，使用对应标签；变更映射直接修改本文件。
