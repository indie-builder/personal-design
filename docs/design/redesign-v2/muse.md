# V2 灵感集：稳定浏览，直接查看

本轮替换上一轮列表和详情构图。依据 `contract.md`、OpenDesign 有效规则和 Impeccable；旧版检查结果不作为本轮体验验收。主任务负责全站视觉截图、生产构建和独立复核。

## 用户任务与新流程

| 用户任务 | 旧版成本 | 本轮处理 | 能力与状态 |
| --- | --- | --- | --- |
| 扫描、比较灵感 | 瀑布流阅读顺序不稳定；大量动效竞争注意力；滚动触发追加改变页面 | 替换为四/三/两/一列规则网格，统一 4:3 contain 静态图/视频海报；仅点击「加载更多」追加 | 155 条内容全部保留；清晰名称、作者、分类；缺预览仍能进入详情；媒体等待最长 15 秒 |
| 查看一件作品 | 图片、视频和标题三个入口有不同去向 | 每件作品只有一个原生链接，图片与视频全部直接详情 | 支持键盘 Enter、修改键新标签页、浏览器原生链接行为；列表不再有灯箱中转或自动播放 |
| 检索 | 筛选与图墙混在一起，查询恢复可能被局部状态覆盖 | 搜索位置固定；分类单行下划线由共享组件实现；结果与清除单独一行 | q/cat 组合、非法分类恢复、无结果清除、URL 刷新与浏览器前后退 |
| 返回继续浏览 | 返回可能丢失批次、焦点或滚动；返回地址只在点击时 JS 计算 | 保存列表 URL、已展开数量、滚动位置、卡片 id；返回链接本身解析到正确 URL | 普通返回和浏览器返回恢复批次/查询；恢复已打开卡片焦点与滚动；storage 不可用时为分类/全部原生链接 |
| 理解作品 | 标题在窄侧栏，媒体先出现且固定空井占据视口 | 顶部返回/相邻导航，随后标题、作者和分类；媒体自然比例；作品信息和来源在媒体下方 | 手机保持相同阅读顺序；无侧栏、面包屑长链或嵌套面板；长标题/描述/标签换行 |
| 看图、看视频 | 列表先弹层再详情；媒体显示与控制角色不清 | 详情内原生 snap 多媒体；图像可进入共享灯箱放大；原始文件为独立外链；视频主动播放 | Home/End/左右、上下媒体边界、原生播放/声音/进度/全屏；非当前视频暂停；RM 下即时移动 |
| 追溯出处 | 原始资料挤在窄面板底部 | 「关于作品」和「原始信息」为媒体下方开放信息区，来源是主操作，JSON 原值内联展开 | 作者链接、真实来源、完整 raw JSON；局部键盘与 Escape 焦点恢复；缺字段有事实性说明 |
| 慢网和失败恢复 | 仅 metadata 到达就提前结束视频加载状态 | loadeddata/canplay 才结束加载；waiting 重新进入有界加载；error 状态不会被 waiting 抹掉 | 15 秒说明、重试、原始文件；图片加载时保留缩略图；视频保留海报。极宽媒体只有失败状态至少 240px，保证恢复控件可达 |

## 页面与源规范对应

- 列表主容器 max 1440px，左右 48/24/20px，标题交给新的 PageHeading。网格 4 列桌面、3 列平板、2 列手机、320px 边界 1 列；整卡不描边，媒体 8px 圆角，16px 标题（手机 14px）。背景/文字/边界采用共享源 token，搜索 placeholder 明确 ink-soft、opacity 1。
- 详情阅读宽度 max 1200px（含页内边距），标题 32/26px、1.35、零字距；作者和类别在同一组。媒体依内容 ratio 决定高度，上限为视口的 70%（手机 65%），不设置固定全屏空井。切换不同纵横比时容器随当前作品调整。
- 关于/来源两列用于宽屏阅读，手机自然纵排；仅分组处用分隔线，不重新包装成卡片。中文正文 14/1.75，描述控制行宽，JSON 12/1.75 并独立滚动。
- 基础按钮、分类、主题由共享组件维护；无动画库、无新增装饰性入场。详情放大使用现有共享灯箱能力并回归触发按钮焦点。
- 全站无菜单导航由主任务外壳承担；本页只有内容上下文返回与相邻作品。

`app/products/muse/**`、`components/plate-wall.tsx`、`components/inspora-media-carousel.tsx` 及相邻 CSS Modules。数据全部通过包 API；未改 catalog、数据库、媒体生成物或共享 UI 文件。既有 route error 恢复入口和 Suspense 文字状态保留。

## 新的可复现行为验证

```sh
node scripts/design-checks/v2-muse.mjs
```

使用项目 Playwright，`DESIGN_BASE_URL` 可配置，默认 `http://localhost:3000`；无绝对用户路径。脚本重新按本轮任务结果写，不复用旧 UI 点击路径或旧报告：

- 静态列表没有 video 元素；每卡只有外层链接；滚动到底仍为 24 条；按钮明确追加到 48 条。
- 第 31 条键盘 Enter 直接到详情，无灯箱中转；返回恢复 48 条、滚动位置和该卡片焦点。
- 非法分类、dashboard + Product 组合、刷新保留、详情后浏览器返回、无结果与清除；视频卡直接详情且原生 controls 开启、autoplay 关闭。
- 标题实际位置在媒体前；媒体高度不超过视口 71%；多媒体 Home/End 与首尾 disabled；放大打开真实 dialog，Escape 关闭并回焦点；真实来源和原始 JSON 可达，JSON ArrowRight 不跳详情。
- dark + reduced-motion 下 1024/390/320 的列表和最长标题详情不横向溢出；尾条边界禁用。
- 原图响应被实际拦截保持未完成，验证 15 秒后重试与原始文件入口；解除拦截点击重试。
- 视频响应被实际拦截，合成一次 `loadedmetadata` 事件，验证它不会取消 15 秒数据等待超时；错误后合成 `waiting` 不抹掉错误。这是客户端事件/状态转换检查，未宣称通过真实网络服务器制造了 metadata-only 流。

现有数据均有作者、来源与媒体；缺字段/无媒体和 route error 分支是实现与代码检查，没有修改真实数据制造样本。waiting 的重新计时实现可读；脚本针对 metadata 和错误锁定事件路径，未把真实视频缓冲全过程记为实测。原始文件外链只验证入口，不保证第三方实时可用。

最终运行结果：`v2-muse.mjs` 六组 PASS、exit 0、零 pageerror；包含新增 metadata-only 事件检查。`pnpm --filter @personal-design/web typecheck` 和上述所有拥有的 TSX 文件 eslint 通过。未采集截图；V2 视觉判断与生产构建由主任务统一完成。

## 原生视频加载标记专项诊断

主任务曾在早期截图看见加载环，并在后续截图怀疑 x204/y444 的小横线残留。对生产预览 `http://localhost:3001` 同一作品 `multi-action-button` 做一次普通动态 / reduced-motion 对照，均等到 readyState 4 后 2.5 秒：

- 两张 390×844 截图字节完全一致，SHA256 均为 `c601a2793877b3028d7bc646b9af85c77e3bedc69415895ffcd4b0a6d0342969`。
- CDP 穿透 Chromium UA shadow tree：`-internal-media-controls-loading-panel` 的 inline / computed display 均为 none，rect `[0,0,0,0]`，animation none；两种模式一致。
- 媒体状态均为 readyState 4、networkState 1、paused true、currentTime 0。
- 对当前 mobile 截图与诊断截图的 x195–213/y436–449 做像素只读检查，无 RGB 三通道均低于 100 的深色像素；当前文件没有复现所述黑色横线。

结论仅限当前捕获：未复现持续 native spinner；没有证据说明全局 reduced-motion 规则造成该问题，不为无法复现的残影修改全局/媒体 UI。早期加载环可作为捕获时机问题保留历史记录，不将它改写为已经定位的 CSS 缺陷。

复现诊断脚本 `v2-muse-spinner.mjs` 已于 2026-10 退役移除，历史记录见 git 历史；当时命令为 `DESIGN_BASE_URL=http://localhost:3001 node scripts/design-checks/v2-muse-spinner.mjs`，记录 UA 控件状态及截图哈希，不写截图文件，以生产预览避免开发工具图标造成无关像素差异。原始临时诊断图是 `/tmp/muse-spinner-no-preference.png` 与 `/tmp/muse-spinner-reduce.png`，不作为可移植验收依赖。

## 独立评审修复：视频首屏播放控件

评审指出旧 70dvh 视频舞台加上标题/导航后，1440×900 和 1024×768 首屏看不到完整原生控制栏。仅视频改为按舞台文档位置测算剩余视口高度，预留至少 64px（或实际工具栏高度 + 12px）；初次 hydration 前采用保守 CSS 回退。图片阅读尺寸未改。

只在 viewport resize、标题/导航尺寸变化、工具栏尺寸变化和字体就绪时重新测算；使用文档坐标避免普通滚动改变媒体尺寸。极长标题/极矮屏保留 240px 最小媒体高度，页面仍可自然滚动。

新增脚本 `node scripts/design-checks/v2-muse-video-viewport.mjs` 实测通过：

| 视口 | 视频底边 | 媒体工具栏底边 | 结论 |
| --- | --- | --- | --- |
| 1440×900 | 835px | 887.89px | 播放和文件控件首屏可见 |
| 1024×768 | 703px | 755.89px | 播放和文件控件首屏可见 |
| 390×844 | 599.09px | 651.09px | 播放和文件控件首屏可见 |

三个视口均验证滚动 150px 不改变视频高度；不重新导航从手机调整到平板后再次正确适配。类型检查与轮播文件 lint 通过。该修复不包含其他审美调整，主任务统一进行评审确认截图。
