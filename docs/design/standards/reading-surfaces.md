# 集合与作品阅读面视觉标准

本文件是 [DESIGN.md](../../../DESIGN.md) 的产品局部标准章节。页面流程由 [页面契约入口](../README.md) 定义；共享按钮见 [控件标准](../controls/README.md)，成对过渡见 [动效标准](motion.md)。

### 分类与主题

两集合支持即时搜索。普通标签分类复用CategoryTabs，灵感集复用CategoryTabs；布局保留分类书籍及既有theme链接筛选，主题图鉴列表可选择对应书页。



### 导航、内容与媒体

全站外壳只提供首页／产品上下文返回和主题操作；首页另有已确认的头像彩蛋。当前层级有返回书架时，由 WorkspaceBack 替换页头动作，不重复添加正文返回栏。

灵感集恢复静态作品网格：中文分类标签、结果数量、纵向自动追加；原生作品链接进入详情。详情显示标题、作者、中文分类、原作、实际说明与媒体；视频原生控制、图片可放大。无放映机、类型旋钮或专注放映台。

布局画册图片点击即放大阅读，不增加二次详情跳转；标题旁的页码目录可直接选图鉴定位，跨页跳转即时。左页页脚放“上一页”，右页页脚放“下一页”；保留页码，首末边界禁用，取消书本两侧悬浮翻页按钮。画册从书架打开时记录一级历史，页头返回和原生后退恢复书脊焦点与位置，不制造重复书架记录。布局灯箱保留焦点约束、Esc、背景inert、滚动锁、加载失败恢复及关闭后焦点回归。

普通作品视频可视时默认静音循环，离屏／后台／减少动态效果暂停；灵感详情播放器保留原生控制。个人网站宣传片是已确认的例外：无原生控制栏，点击或空格／Enter 切换播放，保留可访问名称与焦点；悬停、聚焦或暂停时显示轻量播放提示，加载与缓冲时同一提示位置显示旋转加载指示并保持可见。个人网站两段介绍直接静态展示，不恢复龙卷风或逐字显现。

### AI Coding 词典阅读面

图谱右下角保留收起式搜索：44px圆形入口，展开为最大280px胶囊，搜索在左、清除在右，图标18px / 1.6px；普通输入14px，粗指针16px。使用项目中性主题、单层内描边；聚焦只把同一条边界加深为2px，不叠加外圈、投影或输入框边界。搜索与清除均保留44px操作区，键盘和减少动态效果即时展开。

标题与关闭操作常驻，正文独立滚动；以标题、章节、中英释义、内容定位、逐段完整中英对照、收起的关联术语建立阅读顺序。中文概述不能替代正文译文；中英文同屏，每段对应，原文与译文表格均保留语义。关联术语默认只占一行，展开后按章节提供紧凑原生链接。底部相邻导航显示完整名称并允许换行，首末边界禁用。关闭与 Esc 清除选择并将焦点返回搜索入口；键盘与减少动态效果即时完成。所有尺寸统一使用页头标题旁的返回操作，不另放图谱内返回按钮。移除分享、Copy Markdown 及旧详情组件，不仅隐藏控件。具体流程见 [详情阅读区契约](../execution/ai-coding-dictionary-detail.md)。

### 文字游乐场

新增独立作品 `/products/word-arcade`。游戏区保留黑白像素与文字互动：桌面标题46px／400、小屏32px／400，沿用 Albert Sans 与中文零字距；HUD只显示关卡、剩余目标、积分与机会，13px／小屏12px；操作短句14px；直接选择五款的下划线按钮最小44px。首关以大标题8个文字为目标，标点和副标题不参与碰撞；HUD显示实际剩余目标。删除宣传式副标题、开局目标说明和重复英文名；开始只显示主按钮，暂停／失败／过关仅保留必要短状态，底部只留一行操作短句。像素背景仅游戏区绘制，待机静止，主动开始后随游戏推进；减少动态效果关闭背景移动、文字击飞与碎片，必要的游戏运动保留。无框画布与全站中性双主题相容，不沿用来源站点品牌。

暂停、扣命、结束和过关提供可聚焦操作，得分与状态有文本语义。失焦／后台暂停，继续需主动操作；缩放重排并暂停保留进度。离开页面释放帧循环、动画和输入事件。游戏本身不因键盘输入停用物理，辅助空间动画遵守即时策略。首页复用实际碰撞与绘制函数自动演示打砖块：小球反弹、挡板接球、命中文字，结束后短暂停留重播；仅可视且前台的指针模式运行，离屏／后台暂停并保留进度，键盘／减少动态效果显示完整文字静态预览；点击预览仍进入作品，内页需主动开始。
