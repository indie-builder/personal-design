# 动效增补专项

日期：2026-10-18。基线：`8e4c259`；工作分支：`feat/purposeful-motion-additions`。

## 目标与方向

用户明确要求增加动效：主动发现缺少进入／退出、状态切换和操作反馈的交互并补齐。性能与生命周期检查作为新增动效的质量约束；不以减少已有动效代替交付，不更改布局、内容或产品流程，不新增动画依赖。

本轮动效主线是让用户看清“从哪个状态离开、到哪个状态继续”。高频操作不等待整页编舞；指针路径增加短而连续的衔接，键盘、减少动态效果与后台路径立即到达正确状态。保留现有首页预览、书籍序列、路由过渡、视频与游戏物理。

## 选定场景

| 场景 | 目前缺口 | 增补方向 |
| --- | --- | --- |
| 分类选中 | 每个标签的线单独显隐，缺少位置连续性 | 同行选中线移动并匹配新标签宽度；跨行短交叉淡变，筛选及 aria 状态即时更新 |
| 媒体加载 | 就绪时缩略图与加载提示直接卸载 | 保留缩略图托住高清图淡入，再退出；提示配对淡出，错误／重试保持可操作 |
| 聊天会话 | 新建、历史选择、智能体切换直接替换正文 | 旧会话退场后切换，新会话反向进入；历史恢复与新建方向有别，顶部稳定 |
| 游戏模式 | 直接替换场景，提示层只有进入 | 模式按选择方向退出／进入，物理测量不受 transform 污染；开始／继续提示补退出 |
| 外链意图 | 图标换成箭头，但方向缺少动作表达 | 小范围右上方向反馈，移出归位；无图标／失败箭头保持可见，原生外链不延迟 |

暂不增加普通分类结果的整墙入场，不给所有段落加统一淡入，不重建原生 select，不恢复个人网站已取消的逐字介绍。现有状态已具备完整动效的表面保留。

## 实现与验收范围

五个独立 Subagent 分别负责上述场景，写入范围互不重叠。实现前补充相关 E2E 场景，验证正反方向、中间帧、快速重复、取消、偏好变化、焦点及最终状态；主线程在生产构建上整合验证并独立复审。

设计与浏览器检查分为两个有界批次：先对桌面／小屏、双主题与输入策略统一采样，再集中修正实际发现的问题，最后确认一轮。不得以最终状态或源码存在 animation 代替视觉连续性证据。

当前状态：五项源码实现完成。287项测试、类型、lint、格式、导航、技能库存和设计快照检查通过，Impeccable detector未报告问题。所有维护文件小于20,000 bytes。

- 媒体：生产回归通过，保留高清淡入期间的缩略图，随后退出；加载与错误提示、重试焦点、快速切换、即时策略和卸载均有运行证据。
- 外链：生产回归通过，工具及个人网站的进入／退出中间帧、fallback、键盘、减少动态效果和原生链接属性通过。旧构建红灯及CSS注入自检仅作为检查有效性证据。
- 聊天：隔离假模型／假MCP全套通过，8项浏览器检查、13组会话采样。首轮固定700ms窗口被定位器延迟消耗，误把正常入场中间帧当终态；改为动作返回后有界采样，中间帧断言保留，最终位移0／透明度1。
- 游戏：最终生产构建上的五款真实得分、暂停、重置与全部模式／提示动效检查通过，页面错误0。修复测量交接合并回原模式、子按钮失焦不能取消待启动，以及measured()启动晚于wake()导致不重绘；独立复审无剩余确认问题。
- 分类：已验证首次同行移动、反向接续、跨行淡变、110ms无旧线闪回；后续padding重排暴露24px偏移，按钮ResizeObserver改为border-box后重排回归通过。键盘触发的路由隐藏还会丢失按钮焦点，补回焦点仍为body时恢复原按钮后通过。最后增加空白点击取消恢复标记，避免后续重排抢回焦点，等待最终构建确认。路由Await隐藏祖先会重放layout effect，已保存可见帧并在恢复时接续；重排或即时落定清除旧意图。分类完整专项现已通过，包含偏好／后台、搜索与返回、轮播边界及四档宽度；首轮完整回归20项中19项通过，等待最终全套确认。

桌面1440／1280与390px小屏、亮／暗主题已采样。分类首轮误抓加载态的截图已废弃；修正等待后内容与终态正常，不能代替分类中间帧验收。已完成首轮发现与集中修复，剩余检查用于确认实际缺陷，不继续增加装饰或场景。

## 复现与证据

先按[当前验收入口](README.md#准备生产预览)构建并启动根目录生产预览，设置实际 `DESIGN_BASE_URL` 与 `NODE_EXTRA_CA_CERTS`。

```sh
pnpm check:browser
pnpm check:chat
```

完整浏览器入口包含分类、媒体及外链；隔离聊天不调用真实模型。游戏另在生产预览上执行：

```sh
node --input-type=module <<'JS'
import assert from 'node:assert/strict';
import { withBrowser } from './scripts/design-checks/harness.cjs';
import { verifyWordArcade } from './scripts/design-checks/word-arcade.browser.mjs';
await withBrowser(async ({ page, errors }) => {
  await page.goto(`${process.env.DESIGN_BASE_URL}/products/word-arcade`);
  const cdp = await page.context().newCDPSession(page);
  const result = await verifyWordArcade({
    playwright: page,
    dev: { logs: async () => errors },
  }, cdp);
  assert.equal(result.results.length, 5);
  assert.equal(result.errors.length, 0);
  console.log(result);
}, { pageOptions: { viewport: { width: 1440, height: 900 } } });
JS
```

本地证据位于忽略目录 `.impeccable/review/`：`motion-additions/category.json`、`outward-links.json`、`arcade.json` 及三档尺寸PNG，`media-handoff.json`保存媒体逐帧采样，`chat-checks/result.json`和`analytics-browser-result.json`保存隔离聊天结果。不将包含本地地址或运行日志的原始证据加入公开提交。

限制：后台检查通过覆盖 `document.hidden` 并派发事件验证策略回调，不能证明真实后台节流；触摸真机、其他浏览器引擎及读屏播报未验收。游戏快速键盘操作曾出现模式区域定位偶发超时，基线bundle也能出现；本轮最终定向通过不代表该既有偶发现象已消除。

## 工程约束

- 复用 CSS／原生 WAAPI，以及 `instantMotion`、`observeMotionPolicy`、`playExit`；原有接口不足时优先局部收拢职责。
- 可逆交互必须配对进入与退出，旧 DOM 保留至退场完成；快速操作只提交最后意图，清理旧回调不能误执行过期动作。
- SSR 默认内容可见；动画失败不得隐藏内容或锁住控件。离开层不参与交互或重复播报。
- 不增加全局待机装饰、页面布局动画或通用动效框架；每份维护文本小于 20,000 bytes。
- 不执行真实内容同步、生产写入或未授权发布。原日常同步授权门与本专项独立。
