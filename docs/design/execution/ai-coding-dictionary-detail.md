# AI Coding 词典 · 详情阅读区

## 确认范围

- 使用 Impeccable 的 Read 模式呈现详情；图谱由本站 Next 组件直接渲染，沿用参考布局坐标、浅色章节节点、放射排布、标签避让与收起式搜索。
- 用户选择：关联术语按章节分组，呈现为紧凑文字目录。
- 移除分享、Copy Markdown 和旧详情组件，不能只隐藏按钮。
- 中文释义与英文释义同屏；中文解读与完整英文正文都直接可读，保留术语原名。

## 方向与质量标准

清晰的阅读顺序：标题和关闭 → 章节 → 中英释义 → 内容定位 → 中文解读 → 英文原文 → 关联目录。沿用项目背景、前景与 Albert Sans，不添加卡片、装饰或新色系。内容区独立滚动，标题和关闭始终可见；相邻词条显示完整名称，不滚动文字、不用截断名称代替导航。

桌面阅读区宽度为 clamp(340px,34vw,520px)，图谱为阅读区让出空间；800px 及以下为底部 68dvh 非模态阅读面，保留图谱可见区域。

## 交互契约

- 关闭或 Esc：阅读面退场，选中状态清除，焦点返回搜索入口；键盘和 reduced-motion 即时。
- 点击章节目录词条：图谱与详情同步；标题、语言内容及相关目录同时更新，滚动回到顶部。
- 正常链接、修饰键新标签和浏览器历史保留；切换到搜索结果外的关联词条时清除搜索，防止目标节点被过滤。
- 原文表格使用语义 table；全部内容以 textContent 创建，来源不注入 HTML。
- 内容定位只滚动阅读面，不切换语言、不改变选中的术语。
- 返回作品统一使用共享页头的标题导航，不另放图谱内返回按钮。

## 实现边界

`packages/ai-coding-dictionary` 只提供双语词条、章节与图谱布局；`apps/web/components/dictionary-map.tsx` 管理 URL、搜索和选中状态，`dictionary-graph.tsx` 绘制图谱，`dictionary-detail.tsx` 呈现双语阅读面。页面不加载独立 HTML、iframe 或捕获的 JS/CSS。

## 验收

上述 CDP 记录属于旧 iframe 实现的历史证据；当前原生组件须重新验收直达、中英正文、章节目录、关联跳转、关闭与 Esc、搜索、浏览器返回、双主题、首页预览和小屏。

## 作品级导航

复用 WorkspaceShell 的标题、回退和主题操作，以透明悬浮导航叠放在画布左上角，不占独立行；图谱覆盖整个视口。搜索入口固定在可见画布右下角，展开宽度最多 224px，向左展开而不改变纵向位置；提示文字浮在输入框上方。打开详情时让出阅读面，小屏则置于底部阅读面上方。首页进入、返回及词条打开后的标题回退位置保持一致。


## 首页预览与重新进入

第五个作品的缩略预览复用本站图谱组件，显示连线和浅色节点；预览没有详情和操作控件，不修改首页 URL。仅在可视、前台且允许动态效果时挂载动画，离屏或路由退出释放；静态回退保留节点与连线。

Next Cache Components 的 Activity 可能保留路由 DOM；词典根据当前 URL 初始化状态，退出后再由首页普通入口进入时清除旧搜索、选中与镜头状态。术语直达链接及浏览器历史按当前 URL 恢复。

复验：从首页选中第五项，搜索“缓存”并打开 Prefix cache，经标题回退到首页，再点击第五项；检查 URL 无 term/q、选中为空、搜索为空、阅读面关闭。再次退出和进入仍应一致。检查首页预览可见时出现本站 canvas，离开首页后停止预览动画。
