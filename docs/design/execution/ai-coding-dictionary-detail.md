# AI Coding 词典 · 详情阅读区

## 确认范围

- 使用 Impeccable 的 Read 模式重做详情；这项当前要求取代此前仅针对阅读面保留原版布局及按钮的要求。图谱继续复用原版，保留全屏图谱形态、放大约 15% 的浅色章节节点、放射动效、标签渲染、径向避让与收起式搜索。
- 用户选择：关联术语默认收起，只占一行；展开后按章节分组为紧凑文字链接。
- 移除分享、Copy Markdown 和旧详情组件，不能只隐藏按钮。
- 中文释义与英文释义同屏；完整中文译文与完整英文原文逐段对应，保留术语原名。旧中文概述单独存储，不能充当全文译文。

## 方向与质量标准

清晰的阅读顺序：标题和关闭 → 章节 → 中英释义 → 内容定位 → 逐段中英全文 → 收起的关联术语。沿用项目背景、前景与 Albert Sans，不添加卡片、装饰或新色系。内容区独立滚动，标题和关闭始终可见；相邻词条显示完整名称，不滚动文字、不用截断名称代替导航。

桌面阅读区宽度为 clamp(340px,34vw,520px)，图谱只按阅读区宽度平移；800px 及以下为底部 68dvh 非模态阅读面，保留图谱可见区域。原始图谱不重建。

## 交互契约

- 关闭或 Esc：阅读面退场，选中状态清除，焦点返回搜索入口；键盘和 reduced-motion 即时。
- 点击章节目录词条：图谱与详情同步；标题、语言内容及相关目录同时更新，滚动回到顶部。
- 正常链接、修饰键新标签和浏览器历史保留；切换到搜索结果外的关联词条时清除搜索，防止目标节点被过滤。
- 原文和译文的表格都使用语义 table，行列对应；全部内容以 textContent 创建，来源不注入 HTML。
- 内容定位只滚动阅读面，不切换语言、不改变选中的术语；跳到关联术语时展开折叠区。
- 返回作品统一使用共享页头的标题导航，不另放图谱内返回按钮。

## 实现边界

[dictionary-map.tsx](../../../apps/web/components/dictionary-map.tsx) 承载本地图谱 iframe 与站内 URL／主题同步；[bridge.js](../../../packages/ai-coding-dictionary/runtime/bridge.js) 负责原生 aside 阅读面和逐段对照，[detail.css](../../../packages/ai-coding-dictionary/runtime/detail.css) 负责排版及响应式。词条保存在 [catalog.json](../../../packages/ai-coding-dictionary/catalog.json)，站点交付 [public/ai-coding-atlas/](../../../apps/web/public/ai-coding-atlas/) 的本地运行版本；旧详情及分享、复制控件不挂载。

上游快照与同步、翻译、运行资源准备脚本已于2026-09-27退役，不属于当前实现入口。更新词典需重新捕获上游并重建运行资源，范围以 [PRODUCT.md](../../../PRODUCT.md) 为准。

## 作品级导航

复用 WorkspaceShell 的标题、回退和主题操作，以透明悬浮导航叠放在画布左上角，不占独立行；图谱覆盖整个视口。搜索入口固定在可见画布右下角，展开宽度最多 280px，向左展开而不改变纵向位置；提示文字浮在输入框上方。打开详情时让出阅读面，小屏则置于底部阅读面上方。首页进入、返回及词条打开后的标题回退位置保持一致。


## 首页预览与重新进入

第五个作品的缩略预览复用本地原版图谱运行文件（preview 模式），显示连线、浅色节点与原版动效；预览没有详情和操作控件，不修改首页 URL。仅在可视、前台且允许动态效果时挂载，离屏或路由退出立即释放 iframe；静态回退保留节点与连线。

Next Cache Components 的 Activity 会保留路由 DOM，因此词典在 useLayoutEffect 重新激活时根据本次入口 URL 重新加载 iframe，不复用缓存文档中的搜索、选中或镜头状态；退出时移除消息与历史监听。由首页普通入口进入时，选中词条、搜索和镜头恢复初始状态。术语直达链接及浏览器历史按当前 URL 初始化。

复验：从首页选中第五项，搜索“缓存”并打开 Prefix cache，经标题回退到首页，再点击第五项；检查 URL 无 term/q、focusedSlug 为 null、query 为空、阅读面关闭、iframe performance.timeOrigin 已更新。再次退出和进入仍应一致。检查首页预览可见时出现原版 canvas，离开首页后释放预览 iframe。
