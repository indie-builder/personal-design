# 文字游乐场

## 范围与参考

2026-09-29 用户指定复刻已打开页面上半部的小型文字游戏，随后确认全部五款。仅参考上半部交互，不包含下方“探索游戏”、账号、聊天或生成服务。来源通过 Codex 内置浏览器实看，并核对该区域已加载脚本中的规则。新作品为 `/products/word-arcade`，日期 2026-09-29。

五款：打砖块、贪吃蛇、文字射击、飞字打靶、文字跑酷。黑白像素、标题作为游戏对象、三次机会（贪吃蛇一局）、命中得分、逐关加速。保留站点字体、双主题和共享返回；跑酷角色复用本站时间轴像素精灵，文案移除来源品牌。刷新轮换不重复，页内也可直接选择。无服务端请求、账号或排行榜。

## 失败方式与验收设计

实现前先为模拟器列出并写检查：球穿透文字或挡板、敌弹漏判/重复扣命、未起飞文字被误射、飞字逃脱不扣命、贪吃蛇不增长/穿墙/自咬、空中重复跳跃、越障与撞障混淆、暂停仍推进、重开残留得分与消失文字。新增跨关累计分数检查先复现失败再修复。

浏览器另外覆盖：五款切换清理、刷新轮换、鼠标/触摸/键盘、暂停/重来、调整尺寸、后台/失焦暂停、减少动态效果、深浅主题、1440/1280/390尺寸、首页入口与原生/页头返回。模拟器检查不冒充浏览器操作证据。

## 实际试玩、难度与字体复核（2026-09-29）

### 证据区分

- **普通操作试玩**：逐款使用点击、方向键、空格。文字射击在调整前24目标规则下实际首通，240分、3次机会保留；打砖块观察到20分、贪吃蛇观察到70分、跑酷观察到36分后失误，未记录为手动首通。打靶的即时点击受工具回合延迟明显影响，不能把漏靶结果当作真人反应能力或通关率。
- **浏览器整关辅助验证**：读取真实渲染的球像素或滚字位置，仅发送输入事件，不修改引擎状态、得分或生命。调整后打砖块80分、约48.65秒首通；跑酷229分、约13.80秒首通。结果为`playtest/browser-breakout.json`、`browser-runner.json`；控制器入口`startVisiblePlaythrough`位于原浏览器脚本。
- **模型可解性检查**：读取390/780/1440实际页面几何，固定种子17、理想控制器，五款×三尺寸全部首通。用于证明存在可过关路径，不是玩家胜率或真人耗时；蛇和部分打靶结果来自模型，不能宣称手动全通。重跑：`node scripts/design-checks/word-arcade-playability.mjs .impeccable/review/word-arcade/playtest/layouts.json`。几何采集来自当前页面`[data-game-letter]`的矩形，按场地左上角归一化。

### 发现与调整

1. **目标与节奏**：原先24个目标混入14个小号说明字和2个标点。旧辅助控制在780尺寸曾剩一个句号180秒仍未清空，说明末段会变成低价值的精细瞄准。现在所有模式只将标题文字/数字作为目标，首关8字；标点在开局时隐藏，小号说明始终保留。速度和生命规则没有整体降低。
2. **过关可见性**：HUD新增真实剩余字数，蛇的奖励字母不推进该计数；开始前说明本款目标，失败显示机会/分数，过关显示第几关完成。当前仍为轮换标题、逐关加速的循环模式，没有“打完所有关卡”的终局。
3. **字体与布局**：标题46px/400、手机32px/400，保留全站字体和自动平衡换行；HUD关键数值13px/手机12px、说明14px。开始/继续/下一关使用共享主按钮，最小44px。蛇吃下的字按其原宽度绘制，对应自碰撞也使用真实字宽，避免缩小后的字和碰撞不一致。
4. **键盘与动态偏好**：物理运动不因键盘操作停止；背景与击飞装饰改用共享instantMotion策略，键盘／减少动态效果下静止。

### 难度判断

基于规则、实际输入和上述验证，文字射击最容易上手；打砖块与跑酷需要接球/跳跃节奏，属于中等；贪吃蛇与飞字打靶更依赖持续方向控制和瞄准，属于中偏难。此排序是体验判断，不是用户研究或胜率统计。新增目标提示帮助理解胜利条件，移除小目标改善末段体验，并未把五款都改成无挑战模式。

### UI证据和验证边界

`playtest/ui-before.png`为旧界面；`ui-desktop.png`与`ui-mobile.png`为新界面，另有真实跑酷过关的`runner-clear.png`。五款开始、实际得分、暂停、重开再次通过，控制台错误0；首关目标数为8，副标题目标数为0。保留真机触摸、原有独立浏览器全套未运行的限制；验证浏览器尺寸不等于真机触摸。模型耗时约5–29秒，真实浏览器辅助耗时不同，不作性能或真人通关耗时承诺。
