# AI 问答产品契约

本文件承接 [页面契约入口](../README.md) 的 AI 问答完整流程与实现入口。视觉数值由根 [DESIGN.md](../../../DESIGN.md) 及其 [AI 问答局部视觉章节](../standards/ai-chat.md) 定义；运行、配置和当前验收见 [执行入口](../execution/ai-chat.md)。本文件不另建全站控件标准。

### AI 问答 `/products/ai-chat`

- 第六个作品。所有视口优先沿截图及首版移动视觉与交互，桌面居中480px竖向窄框，手机填满共享页头下方；统一15px页头、欢迎标题与13px消息／列表；按钮13px、标签12px，全部实际输入值、占位与空／已选下拉统一13px：智能体选择器居中，保留左侧 Menu 会话记录与右侧 Plus 新对话。欢迎语与三个大触控问题选项位于消息区，选项包含自然语言问题与一句结果说明，点击直接发送，不显示向上箭头或快捷键；空态和有消息时输入区默认停靠底部，离开最新消息区域时隐藏，回到最新消息时恢复。
- 消息交互：只有当前最后一条已完成的assistant回答可编辑和执行生成动作；历史表单与按钮锁定。表格分页／横滑、Tabs、Accordion、条目展开和复制仍可查看；提交新问题即锁定旧回答，刷新保留填写结果。
- 标题回退导航置于手机展示框外，复用其他作品的共享页头样式；宽屏标题独立定位，手机框保持顶部16px，不受外层标题挤压；不足800px时为页头预留72px避免导航重叠，不产生页面级纵向溢出。问答页继续隐藏主题入口，其他作品不变。
- 页面与表面遵循全站中性双主题、Albert Sans 和中文零字距；所有图标为中性色，浅蓝只用于局部消息角色、选中和焦点等状态。输入区聚焦只显示连续外轮廓，不出现 textarea 内框；移除“回答可能有误，请核实重要信息”，不添加替代免责声明。视觉数值与局部圆角例外见根 DESIGN.md。
- 智能体选择器打开页头下方居中的原生 auto popover 下拉列表，点击外部或 Esc 可收起；创建智能体进入覆盖同一移动界面的全高表单页，顶部返回、标题居中，仅有名称与系统提示词，底部常驻全宽创建按钮。Menu 打开贴齐聊天框左侧的全高导航抽屉：框外共享页头始终显示“← AI 问答”，抽屉顶部为“对话”标题，右侧关闭；新对话与历史记录占据导航内容区，不展示外观入口或保存位置说明。
- 默认欢迎区提供「从头帮我们选一套协作方案」「帮我们安排两周试用」「看看两周试用的效果」三个业务入口；内置轻舟协作案例，覆盖需求、对比、计划、图表复盘与决策。已移除 Alt 快捷键和提示图标。头像由包同步脚本从用户提供的20张图片生成（根目录 `pnpm sync:ai-chat-avatars <zip路径>`，zip 需含 `young-avatars-20/waker-young-001–020.png` 与带性别元数据的 `prompts.json`，校验失败不改写现有头像），使用其中15张男生头像随机分配并保存，已有女生头像自动替换；旧默认助手更名时保留会话和自建智能体。
- 智能体创建只有名称与系统提示词。默认「生成式 UI 助手」；选择其他智能体开始独立会话；历史记录恢复原智能体和上下文。记录仅存当前浏览器，不提供账号或跨设备同步。
- 内置第二个智能体「智能问数」分析虚构公司星辰科技的仿真 HR 数据，查询期间在等待区显示工具步骤（运行／完成／失败），回答开始后收起。欢迎区示例按智能体区分：生成式 UI 助手为三个选型入口，智能问数为在职人数、部门分布与人力成本趋势，自建智能体不显示通用示例。数据工具由服务端白名单注册并只读执行，访客可见处不出现数据来源站点引用。
- Pi Coding Agent 的 `AgentSession` 后端调用智谱 Coding Plan，前端使用 OpenUI 官方 NDJSON adapter 接收流式消息，OpenUI 官方82个组件定义与 Renderer 渲染受控 React 组件。生成表单和按钮可直接追问；不执行模型生成的任意 HTML、脚本或外部工具。
- [OpenUI移动端通用契约](../controls/openui-mobile.md)约束全部schema组件，区分渲染器强约束、生成建议和业务智能体。默认案例不是组件模板；普通内容可不带表单或操作，字段／表格维度建议不得导致数据丢失。
- 生成回答沿用移动端阅读尺度，通用 Card 去外框；选择项和编辑条目用分隔行，指标以紧凑标签／数值行呈现，回答、portal和编辑操作区铺满可用宽度：单个满行；内容容器宽于320px时两个短操作等宽并排，窄容器或三个及以上操作纵向满行；每组最多一个primary，编辑确认填充、撤销描边，表格仅内部横滑。全部官方组件及其 body portal 继承聊天外壳的语义字号与双主题图表配色，字段与动作使用20px行盒，按13px文字统一控件比例；回答图标14px、组间距12px；文字按钮圆角10px、最小高44px、padding为10px 12px；导航、发送、复制仍为图标操作；原生日期／下拉、已有字段、确认／撤销及业务步骤保持不变。
- 连续追问携带上下文。未压缩区超过16条或24000字符时，通过 Pi `ModelRuntime.completeSimple` 整理早期对话为摘要，最近6条保留原文。摘要只保存在 Conversation.memory，与原始消息一起持久化；下次请求仅发送摘要与其后的原始消息。摘要失败时返回可重试错误，不丢弃原始记录。
- 回到最新消息按钮居中于手机框；内层智能体栏在手动向上滑动时收起、反向滑动时恢复，以180ms位移／淡变呈现，不改变消息区高度，自动跟随回复不会隐藏。下拉与导航有成对进入／退出；创建页在手机框内进入与返回，保留退出DOM到结束，再切换状态。新消息首次轻入场，流式片段不重复播放；等待点仅生成中运行。键盘、减少动态效果与后台路径即时完成，快速反向及重复提交保持稳定。验收见执行文档的动效专项。
- 支持停止、重新生成、失败重试、格式错误提示及一次结构自动修正。等待提示仅生成期间显示；结束后消息底部出现复制按钮，最新回答同时显示重新生成按钮，均为44px中性圆形触控按钮，复制渲染后的正文并反馈成功／失败。生成期间禁用会话／智能体切换，防止回复串入其他会话。离开页面中止正在生成的回答。
- 导航抽屉使用原生 dialog；创建页是聊天容器内部的独立 section，原聊天保持挂载作为退场底层，并在创建页活动期间 inert、对辅助技术隐藏。创建页不自动弹出键盘，名称回车进入提示词，返回／Esc 回到列表并保留本次草稿，成功后清空草稿；输入正文可独立滚动，手机键盘出现时按 visualViewport 保持提交区可见。抽屉支持 Esc 和焦点回归；深色主题复用现有主题机制。桌面 Enter 发送、Shift+Enter 换行，触摸端 Enter 保留换行；输入法组合期间不误发送。
