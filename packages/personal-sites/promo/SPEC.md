# 陈远 · 个人网站宣传片

创作模式：用户于 2026-09-09 选择自主创作。制作放行：已对照公开网站与本项目第三个作品的定位，采用下面的分镜。

## 产品简报与执行决策
| 需求 | 执行 |
| --- | --- |
| 用途 | 个人设计第三个项目的详情页，替换旧 walkthrough 录屏 |
| 受众 | 希望了解陈远工程经历与内容整理方式的访客 |
| 核心表达 | 个人工程档案：记录动态、收藏内容、深入阅读开源项目 |
| 必须展示 | 人物身份、技术词条、每日动态、每日关注、设计收藏、开源关注与项目详情 |
| 画幅与时长 | 1920×1080，30fps，36 秒；中文，无配音 |
| 数据 | 仅用户指定公开网站；不登录、不提交问一问、不访问内部资料。2026-09-09 快照冻结，不虚构指标或功能 |
| 音频 | 完全无声，不保留音轨；用户最终要求取消所有背景声音与转场音效 |
| 交付 | 原生控件主动播放；网页使用 faststart H.264 MP4 和独立封面；工程可重新渲染 |

## 视觉方向
候选：①工程档案（采用）：中性色、真实页面、定向取景；②暗场技术发布：削弱阅读，弃用；③速切社交广告：无法看清细节，弃用。

来自线上 computed styles：SF Pro Text / SF Pro Display / system-ui / PingFang SC；正文 rgb(28,28,30)，辅助 rgb(111,111,114)，白底。截图使用原生字体；片中字卡使用 system-ui/PingFang SC，中文零字距，96/72/40px 层级，行高1.35。布局 96px 安全边距、细分隔线，页面圆角8px。墨色 #1c1c1e、白色 #fff、浅灰 #f6f6f6。无霓虹、彩色渐变、金粉、手持抖动。

动效词：清晰、沉稳、精准。专业信赖基准，无弹跳的推移 30–48f，row-embed 保留源码轻微落地回弹。品牌 hold ≥30f，批量入场后静止 ≥15f。中间功能镜头以平视可读为主，轻微透视只用于片尾前的页面交接。画内不叠加细小字幕；解说放在独立标题区。

## 功能与镜头映射
| 功能 | 主选卡 / 变体 | 备选与取舍 |
| --- | --- | --- |
| 人物身份 | brand-ink-open / 同名 | 不用 spotlight 重光效，保留原头像；无暖纸和琥珀色 |
| 每日动态 | row-embed / 同名 | 用真实行切片与坐标归位，不另画 UI |
| 每日关注、设计收藏 | word-relay-filmstrip / 同名 | 真实页面步进，一次切词对应一张图；无持续滚动；字体改产品 sans，白/深框区分而不篡改页面颜色 |
| 开源阅读引导 | blur-slide / 同名 | 中文按语义分4组，三通道共用进度 |
| 开源列表到详情 | PageCam 关键帧推近/换页 | 原创范围仅取景与匹配剪辑；风险是长页裁切，逐帧检查标题与正文 |
| 品牌收尾 | 原创头像与文字 lockup | 不套多功能合影，避免同一页面重复陈列；放大清楚的URL |

## 分镜
| # | 时间 | 镜头 | 关键动效 |
| --- | --- | --- | --- |
| 1 | 0–4s / 0–119f | 陈远，个人工程档案；真实头像及技术词条 | brand-ink-open 准星→逐字压印→副标；落定后留1秒；7f退出 |
| 2 | 4–10s / 120–299f | 每日动态：把每天的变化，整理成可读的线索 | row-embed：3条真实内容12f落位、9f间隔，PageCam缓慢取景；末段停留 |
| 3 | 10–18s / 300–539f | 每日关注 / 设计收藏；把值得回看的内容留下 | filmstrip 16f步进、先出后进，两张截图交替；≥2s阅读每张；图词中点同为540 |
| 4 | 18–22s / 540–659f | 开源关注，不止一个 Star；从收藏，走进项目本身 | blur-slide按语义词组，48f内落定，hold |
| 5 | 22–30s / 660–899f | 开源列表 → 仓库阅读页：中文阅读、原始出处与个人判读 | 前90f列表缓推，接90f详情稳定取景，最后60f展示真实 GitHub 出处按钮；真实页面 |
| 6 | 30–36s / 900–1079f | 头像、陈远；打开个人网站；default-coder.lovemyrmb.cn | 头像平稳进入、文字锁定，末端≥60f静止；无重复标语 |

页面截图未读小字为真实 UI 纹理，以标题区域说明功能；重点标题与URL达到≥56/32像素有效字高。

## 素材与 QA
参考源码与 Gallery 索引保存在 references/，官网样片按索引 media 路径下载供独立终检。每镜两个静帧、整片抽帧与切缝检查。独立审查使用干净上下文 subagent。

## 实施补充

最终素材重新采集时把自动化指针移至头像外的姓名区，产品画面取景不包含该处；网页翻译工具不进入片中。阅读相机最终保持仓库标题、判读和中文阅读开头同时可见，cy 300→340；不沿长文继续下摇而裁掉标题。Gallery filmstrip 的衬线改为原站 sans；继承530px等高、635px步进、16f窗口与先出后进；两张不同内容卡在白/深边框上区分，原页面不反色。

独立终检后的定案：开源列表 cx 改为1070，使左侧分类完整；阅读段最后2秒放大真实“在 GitHub 查看仓库”切片（4x采集），清楚展示原作入口。开场保留技术词条纹理，同时加40px的 Java / TypeScript / Python 作为可读身份关键词。blur-slide卡片文字声称主副32f重叠，但准确demo嵌套seg实算主标37.8f结束、副标38.8f开始；沿准确demo实现，不强改成文档的错误解释。

## 无声交付
用户决定取消所有背景声音与转场音效。工程只包含画面，使用 `--muted` 导出不含音轨的成片。详情默认自动循环播放，不展示功能截图。
